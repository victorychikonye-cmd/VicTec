## Run locally
Open `index.html` in a browser, or upload the folder to GitHub Pages / Netlify / another static host.

## Contact form
The enquiry form uses a `mailto:` link. It opens the visitor's email application with the message addressed to victorychikonye@gmail.com. It does not send or store messages automatically.

## WhatsApp
